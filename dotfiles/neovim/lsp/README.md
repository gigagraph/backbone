# LSP - Language Server Protocol

Supported LSP servers:

- [Lua](./lua.md).
- [C and C++ (+ CUDA)](./c-cpp.md).
- [Rust](./rust.md).
- [Go](./go.md).
- [Python](./python.md).
- [Markdown](./markdown/README.md).
- [SQL](./sql.md).
- [Bash](./bash.md).
- [Latex][./latex.md].

Planned to be supported in future:
- Zig/Ziggy/Ziggy Schema.
- Verilog.
- VHDL.
- AWK.
- Scala (`metals`).
- Kotlin (`kotlin_language_server`).
- Gradle (`gradle_ls`).
