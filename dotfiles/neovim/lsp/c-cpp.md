# C and C++ LSP

This guide recommends using [`clangd`][clangd] as an implementation of LSP server for C and C++ programming languages.

> [!NOTE]
>
> `clangd` also works for [some cuda files][clangd-cuda-support].

## Installation

This guide recommends installing `clangd` by following [instructions to install LLVM toolchain from this repo](../../../system-setup/toolchains/llvm/README.md). Alternatively, users can follow the [official `clangd` installation instructions][install-clangd].
